# Audit mathématique

Le workflow manuel `Audit mathematique 65 modules` produit `math-audit.json` et `math-audit.md` en artefact. Une génération fonctionnelle ne vaut pas validation mathématique. Le statut `unverified` signale qu'aucun oracle indépendant n'a validé la question. Le workflow échoue tant que tous les modules ne sont pas couverts ; c'est intentionnel. Étendre les oracles aux formats restants avant de considérer l'audit terminé.
